### A. Screen Inventory

1. **History -> Emails (`Campaigns` Sub-Tab)**
   - **Purpose:** Tracks bulk/scheduled campaign broadcasts sent across modules.
   - **Components:** Search input (`Search by subject line...`), Sub-tabs (`Campaigns`, `Sent Emails`, `Errors`), Data Table (`Subject Line`, `Module`, `Total Recipients`, `Unique Opens`).

2. **Campaign Details Modal**
   - **Purpose:** Shows read-only overview and email body template of a sent campaign.
   - **Components:** Metadata fields (`SENT BY`, `SENT AT`, `RECIPIENTS LIST`, `TOTAL RECIPIENTS`, `UNIQUE OPENS`, `UNIQUE CLICKS`), `Subject` text, Template Body preview with dynamic token tags, `Close` button.

3. **History -> Emails (`Sent Emails` Sub-Tab)**
   - **Purpose:** Logs individual email delivery instances to recipients.
   - **Components:** Data Table (`Recipient`, `Subject`, `Status`, `Sent By`, `Sent At`), Pagination bar.

4. **History -> SMS**
   - **Purpose:** Logs SMS text communications sent to contacts.
   - **Components:** Search input (`Search by name or phone number...`), Filter chips (`Show All`, `Errors`), Data Table (`Recipient`, `Phone Number`, `Message`, `Status`, `Sent By`, `Sent At`).

5. **History -> Exports**
   - **Purpose:** Stores generated downloadable exports (content archives, headshots, session files).
   - **Components:** Data Table (`Export File Name`, `Exported At`, `Size`, `Status` / Action), Green `Download` buttons.

6. **History -> Audit**
   - **Purpose:** Immutable audit trail logging field-level modifications across entities.
   - **Components:** Search bar (`Search audit logs by keyword...`), `View Legacy Audit Log` button, Filter chips (`Logs`), Data Table (`Subject`, `Type`, `User`, `Action`, `Field`, `New Value`, `Occurred At`).

---

### B. Feature / Capability List

1. **Email Activity Audit & Tracking:**
   - Categorize email logs into aggregated `Campaigns` and individual `Sent Emails`.
   - Track campaign-level recipient counts, open counts, click counts, author, and timestamp.
   - Template body rendering with dynamic variable tag replacement (e.g., `@[recipient.first_name]`, `@[title]`).
   - Deliverability status tracking per message (`Dropped`, `Open`, `Delivered`, `Processed`).

2. **SMS Logging:**
   - Track outbound text messages with recipient name, masked phone number, truncated preview, delivery status, sender, and timestamp.
   - Filter by error states (`Errors`).

3. **File Export Management:**
   - Centralized repository storing background-generated files.
   - Displays exact file name, timestamp, formatted file size (KB/MB), and direct `Download` action.

4. **System Audit Log:**
   - Full history tracking updates to `Contact`, `Session`, `Group`, and `Evaluation Plan` entities.
   - Capture subject name, entity type, actor (`User`), action type (`Update`), target field name, sanitized raw value, and timestamp.
   - Keyword search across audit logs.
   - Link out to legacy logs (`View Legacy Audit Log`).

---

### C. Data Model Signals

- **Campaign:** `subject_line`, `module` (Accounts, Sessions), `sent_by`, `sent_at`, `total_recipients`, `unique_opens`, `unique_clicks`, `body_template`.
- **Sent Email:** `recipient_name`, `subject`, `status` (`Dropped`, `Open`, `Delivered`, `Processed`), `sent_by` (User or System), `sent_at`.
- **SMS Record:** `recipient_name`, `phone_number`, `message_text`, `status` (`Delivered`, `Failed`), `sent_by`, `sent_at`.
- **Export Item:** `file_name`, `exported_at`, `file_size_bytes`, `download_url`.
- **Audit Log Entry:** `subject_name`, `entity_type` (Contact, Session, Group, Evaluation Plan), `user_name`, `action_type` (Update, Create, Delete), `field_name`, `new_value`, `occurred_at`.

---

### D. Organizer vs Participant

- **Organizer (Admin / Event Team):** All sub-modules within the History page (`Emails`, `SMS`, `Integrations`, `Exports`, `Audit`) are exclusively accessible to event organizers to monitor team actions, verify outgoing messaging, and download generated data exports.
- **Participant (Speaker / Evaluator):** No direct access to the History module. Participants trigger entries indirectly when updating profile/session info or receiving automated notifications.

### E. UX/UI Craft Notes

- **Sidebar Geometry:** Left sidebar fixed at ~240px width with grey item text; active module highlighted with bold text and dark neutral background.
- **Header & Navigation:** Sub-tabs rendered as horizontal line-styled tabs beneath the main top navbar.
- **Table Structure:** Standardized borderless rows, left-aligned text columns, right-aligned pagination controls (`Show X` dropdowns on right).
- **Color Codes:**
  - Active tab text: Primary Blue (`#1890FF` / Sessionboard Blue).
  - Primary Action / Download Buttons: Vibrant Solid Green (`#52C41A` / `#28A745`).
  - Action Pills in Audit Log: Soft Light Blue pill badge with navy text for `Update`.
  - Delivery Status Text: Muted gray/neutral formatting for log table statuses.
- **Modal Design:** Centered overlay with solid blue header bar (`View Campaign Details`), structured 2-column key-value panel on left and dark border preview box on right for email text.
