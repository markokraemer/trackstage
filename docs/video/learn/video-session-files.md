### A. Screen Inventory

1. **Session Settings - Files (`Sessions -> Settings -> Files`)**
   - **Purpose:** Configure global file upload rules, restrictions, and file properties for session submissions.
   - **Components:** `Agenda`, `Criteria`, `Personas`, `Rooms`, `Tracks`, `Levels`, `Formats`, `Languages`, `Files` sub-tabs; `Enable File Upload` switch; `Due Date` date/time picker; `Accepted File Formats` tag/chip input; `File Limit` stepper; `Limit File Size` switch; `Minimum File Size`, `Maximum File Size`, `Type` inputs; `Enable Comments` switch; `Save` button.

2. **Portals Tasks (`Portals -> Tasks`)**
   - **Purpose:** Manage tasks assigned to portal users (e.g., instructing speakers to upload files).
   - **Components:** `Search tasks by name` bar, `+ Add Task` button, task list table (`Name`, `Type`, `Method`, `URL Value`, `Actions`).

3. **Update Task Modal**
   - **Purpose:** Create or edit portal task instructions and direct external links.
   - **Components:** `Enter Description` / `Use Field` radios, Rich Text toolbar, `Task Link` radios (`Enter Task URL` / `Use Field`), URL input, `Update Task`, `Cancel` buttons.

4. **Speaker Portal - Keynote Session Drawer (`Participant View -> Sessions -> [Session Drawer] -> Files`)**
   - **Purpose:** Allow speakers to drag and drop required session files and review upload constraints.
   - **Components:** `Details`, `Tasks`, `Files`, `Participants` tabs; upload requirement summary; dropzone; `Upload` button; `Session Files` list section.

5. **Session Details - Files Tab (`Sessions -> Submissions -> [Session] -> Files`)**
   - **Purpose:** Organizer view of submitted session files, comment threads, and file version history.
   - **Components:** `Details`, `Participants`, `Files (#)`, `Submissions`, `Audit` tabs; upload dropzone; file cards; `Comments (#)` toggle; `History (#)` toggle; comment list; `Enter your comment` input; `Add Comment` button; version history list items with action menus (`...`).

6. **Select Fields to Show/Hide Modal**
   - **Purpose:** Customize table column views across session management list screens.
   - **Components:** `SESSION FIELDS` list; search bar; `All Fields`, `Global`, `Event` filter tabs; field selection checkboxes; `Showing # fields` reorder list; `Update View` button.

7. **Download Files & Folder Structure Modals**
   - **Purpose:** Configure bulk file export structure and generate asynchronous download archives.
   - **Components:** `Group files by: Content type, Date, Room, Session` link; `Folder Structure` form with dropdowns (`GROUP FIRST BY`, `THEN BY`, `THEN BY`); folder tree preview; `Generate Download` button.

---

### B. Feature / Capability List

- **File Upload Configuration:** Enable/disable file submissions per event; enforce submission due date/time; restrict accepted file extensions (e.g., PDF, PPT, Word); set max file count limit per session (numeric stepper); set custom min/max file size limits (up to 1.95 GB).
- **Speaker Task Directives:** Create custom portal tasks with rich-text upload instructions and external link guidance.
- **Participant Upload Drawer:** Interactive drag-and-drop file upload zone displaying explicit event deadline and file extension rules.
- **Organizer File Management:** View submitted files inside individual session details; preview file metadata (uploader, timestamp, version number).
- **File Commenting:** Integrated comment threads per file; support for organizer `Admin` tags; manual notification note (email notifications are not sent automatically on comment posting).
- **File Versioning:** File version history tracking (`v1`, `v2`, etc.); view timestamp and uploader for previous revisions.
- **Custom Table Views:** Show/hide `Files` column in session data tables; persist view configurations via `Save View`.
- **Bulk File Export & Hierarchy:** Bulk select sessions or files; paginate up to 100 items per page; configure 3-tier nested folder directory exports (grouped by Date, Room, Session, Content Type); asynchronous download generation with email link notification.

### C. Data Model Signals

- **Event Setting:** `Enable File Upload` (Boolean), `Due Date` (Timestamp), `Accepted File Formats` (List of Strings), `File Limit` (Integer), `Limit File Size` (Boolean), `Min File Size` (Float), `Max File Size` (Float), `Size Unit` (Enum: `GB`, `MB`), `Enable Comments` (Boolean).
- **Task:** `Name` (String), `Type` (Enum: `Contact`, `Session`, `Group`), `Method` (Enum: `Manual`, `Automated`), `Description` (Rich Text), `Task Link URL` (String).
- **Session:** `Session ID` (String), `Title` (String), `Status` (Enum: `Accepted`, `Pending`, `Declined`, `Draft`), `Files Attached Count` (Integer), `Track` (String), `Starts At` (Timestamp), `Ends At` (Timestamp), `Room` (String).
- **Session File:** `File ID` (String), `Title / File Name` (String), `MIME Type` (String), `Size` (Float/String), `Uploaded At` (Timestamp), `Uploaded By` (User Reference), `Version` (Integer), `Category/Tag` (Enum: `Presentation`, etc.).
- **File Comment:** `Comment ID` (String), `Author` (User Reference), `Author Role Badge` (Enum: `Admin`, `Speaker`), `Timestamp` (Timestamp), `Text` (String).

---

### D. Organizer vs Participant

- **Organizer Side:**
  - Configuring global session file rules, limits, and due dates (`Sessions -> Settings -> Files`).
  - Creating portal upload tasks (`Portals -> Tasks`).
  - Accessing organizer file list (`Portals -> Files` or `Content -> Files`).
  - Reviewing, commenting on, and managing versions of uploaded session files (`Sessions -> Submissions -> [Session] -> Files`).
  - Customizing table field views (`Show/Hide Fields`).
  - Executing bulk file downloads and configuring export folder structure (`Download Files`).

- **Participant Side:**
  - Viewing assigned file upload tasks and instructions in the Speaker Resource Portal.
  - Selecting an accepted session and opening the right-hand side drawer.
  - Uploading session files via drag-and-drop within specified constraints.
  - Communicating with organizers via file comment threads.

### E. UX/UI Craft Notes

- **Layout Geometry:** Left sidebar navigation menu (~240px wide) with expandable sub-menus; content layout utilizes top page headers with breadcrumbs; side drawers overlay screen content from the right edge (~450px wide).
- **Button Hierarchy:**
  - Primary actions: Solid orange buttons (`Save`, `Update View`, `Generate Download`, `Download Files`).
  - Secondary/Modal actions: Solid blue buttons (`+ Add Task`, `Update Task`, `+ Add File`).
  - Neutral/Cancel actions: White buttons with gray borders (`Cancel`, `Clear selected`).
- **Table Density & Controls:** Compact, full-width table layout; top controls feature search input, view filters, bulk selection counter banners, and bottom-right pagination dropdowns (`Show: 25`, `Show: 100`).
- **Status Badges & Colors:**
  - `Accepted`: Green rounded pill badge with checkmark icon.
  - `Pending`: Yellow/orange rounded pill badge.
  - `Declined`: Red rounded pill badge.
  - `Admin`: Neutral gray pill badge.
- **Form Layout:** Field labels positioned directly above inputs; helper text rendered in small light-gray body font below fields; switches use standard green active toggles.
