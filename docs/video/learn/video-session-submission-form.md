### A. SCREEN INVENTORY

1. **Organizer Dashboard (`Dashboard -> Speakers`)**
   - **Purpose:** Overview of onboarding, file statistics, and form submissions.
   - **Components:** Nav sidebar (`Dashboard`, `Contacts`, `Exhibitors`, `Sponsors`, `Sessions`, `Portals`, `Content`, `Studio`, `Event Team`, `Settings`), metric cards (`Session Files`, `Sessions With Uploaded Files`, `Comments Today`, `Exports Generated`), submission cards, and actions (`+ Manage Forms`, `Edit Portal`).

2. **Submission Forms List (`Sessions -> Submissions -> Forms`)**
   - **Purpose:** Central hub for creating, managing, and viewing submission forms.
   - **Components:** Tabs (`Submissions`, `Forms`), search bar (`Search forms...`), status filter pills (`All Forms`, `Open`, `Closed`), sort selector (`Sort by: Most Pending`), primary button (`+ Create Submission Form`), form card items with `OPEN` badges, metrics, and context menus (`Open`, `Edit`, `View Results`, `View Draft Submissions`, `Duplicate`, `Delete`).

3. **Form Builder Wizard Modal (`Edit Session Form`)**
   - **Purpose:** 4-step wizard to configure form structure, fields, limits, and notifications.
   - **Components:** Step tracker (`Welcome Screen`, `Session Information`, `Speaker Information`, `Form Settings`), inputs for internal/external names, 15-char page headings, rich text welcome/success message editors, drag-and-drop question lists with required toggles, inline formatting insertion bar (`H1`, `Tr`, `-`), numerical steppers, datepicker, and admin notification dropdowns.

4. **Select Fields Modal (`Select fields`)**
   - **Purpose:** Select existing custom/standard fields or initiate new field creation.
   - **Components:** Search filter (`Filter fields...`), tabs (`All Fields`, `Global`, `Event`), source field list, selected fields pane, `Cancel`, `Done`, and `+ Create New Field` button.

5. **Add Custom Field Modal (`Add Field`)**
   - **Purpose:** Create custom event or global data fields.
   - **Components:** `Field Name *`, `Field Type` dropdown, `Field Description`, `Maximum Length`, `Field Level` dropdown (`Event Field`, `Global Field`), `Save`, `Cancel`.

---

### B. FEATURE / CAPABILITY LIST

- **Form Management:** Create up to 20 forms per event; preview forms via context menu (`Open`); duplicate or delete existing forms.
- **Form Wizard Customization:** Set internal name and public title; define page headings (15-character limit); embed rich text instructions and welcome copy.
- **Field Configuration:** Enforce required fields (`Title` and `Description` for sessions; `First Name`, `Last Name`, and `Email` for speakers are mandatory); customize labels and help text; set conditional display logic via `Use question rules`; reorder, disable, or remove fields without deletion.
- **Inline Layout Elements:** Insert headers (`H1`), rich text instructions (`Tr`), and horizontal rules (`-`) directly between form questions.
- **Contact & Portal Handling:** Toggle contact updates for existing profiles; automatically notify existing contacts via email with portal access instructions.
- **Settings & Limits:** Set strict form close dates; enable automated reminder emails (sent 5 days and 1 day prior to deadline); select admins for submission/update alerts; cap submitter speaker limit (max 15 on submitter side, backend overrides allowed); cap total submissions per user; customize confirmation emails and success screen copy; configure 10-second auto-redirect to portal.

---

### C. DATA MODEL SIGNALS

- **Form Entity:** `Internal Form Name`, `External Form Title`, `Page Headings` (Welcome, Session Data, Speaker Info), `Welcome Message`, `Close Date`, `Reminder Email Enabled`, `Speaker Limit` (max 15), `Submission Limit`, `Success Message`, `Auto Redirect Toggle`.
- **Session Field Entity:** `Title`, `Description` (mandatory required fields), `Format`, `Tags`, `Track`, `Level`, `Field Level` (`Event` vs `Global`), `Field Type` (`Text`, `Dropdown`, `Checkbox`, etc.), `Help Text`, `Conditional Logic Rules`.
- **Speaker / Contact Entity:** `First Name`, `Last Name`, `Email` (mandatory required fields), `Biography`, `Headshot`, `Company Name`, `Job Title`, `Mobile Phone`, `Home Phone`.
- **User Roles & Notifications:** `Admin User` (receives submission/update notification emails), `Submitter / Contact`.

---

### D. ORGANIZER vs PARTICIPANT

- **Organizer Side:** Creating/editing forms, defining question logic and custom fields, establishing close dates/limits, configuring admin alerts, and managing submitted proposals.
- **Participant Side:** Filling out submission form steps, receiving automated reminder/confirmation emails, viewing customized success messages, and accessing the speaker portal to manage profile details.

---

### E. UX/UI CRAFT NOTES

- **Layout & Structure:** Fixed dark-grey left navigation sidebar; centered modal builder featuring a step-based progress header.
- **Color Scheme & Accents:** Dark text on clean light grey backgrounds; vivid blue (`#1890FF`) primary action buttons; orange (`#F56C6C`) primary save buttons; green pill badges for `OPEN` status indicators.
- **Interactive Elements:** Hovering between form questions displays a full-width blue insertion line with inline quick-add controls (`H1`, `Tr`, `-`); three-dot context menus trigger explicit dropdown action lists.
- **Form Controls:** Labels placed directly above inputs; blue hyperlinked affordances for help text; rich text toolbars attached to content blocks; numerical steppers flanked by `+` and `-` buttons. Max character rules enforced on header fields (15 characters) and text inputs (255 characters default).
