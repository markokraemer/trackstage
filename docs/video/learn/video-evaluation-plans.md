#### [00:54 - 01:36] Step 2: Configuration — Toggles & Settings
**NARRATION:**
Additionally, there are four settings you can configure. Set Plan as Open. If enabled, you can set a due date. If the plan remains closed, you can open the plan at a later date. Until then, plans are view-only to evaluators. Enable Anonymized Review. The first and last names of session speakers are removed from submission details. Enable Weekly Reminders. Send an automated email to evaluators every Monday when there are sessions to review in their plan. Include Uploaded Files. Toggle this option on if you want evaluators to view and access any files uploaded to sessions. To learn more about this feature, watch our session files training video.

**SCREEN:**

### A. Screen Inventory

1. **Evaluation Plans Dashboard Page**
   * **Purpose:** High-level overview and table management of all evaluation plans.
   * **Components:** Main Navigation Sidebar, Header (`Evaluation Plans`), Action Button (`+ Add Plan`), Data Table (`Name`, `Status`, `Evaluators`, `Sessions`, `Total Evals`, `Progress`, `Due Date`, `Actions`), Row Action Dropdown (`Review`, `Edit`, `Open`, `Export`, `Duplicate`, `Delete`).

2. **Evaluation Plan Creation Wizard (Steps 1–6)**
   * **Purpose:** Step-by-step creation and setup for evaluation plans.
   * **Components:**
     * *Step 1 (Type):* Option Cards (`Assign Evaluators`, `Virtual Evaluators`).
     * *Step 2 (Configuration):* Inputs (`Title *`, `Instructions *`), Toggles (`Set Plan as Open`, `Enable Anonymized Review`, `Enable Weekly Reminders`, `Include Uploaded Files`).
     * *Step 3 (Evaluators):* Search bar, Checkbox list, Selection summary panels (`Invited Evaluators`, `Added Evaluators`).
     * *Step 4 (Session Filters):* Boolean Rule Builder (Fields, Operators, Values, `AND`/`OR` logic, Match counter).
     * *Step 5 (Display Fields):* Tabs (`Session Fields`, `Speaker Fields`, `Evaluation Fields`), Field selector lists, Field Customization Side-Drawer (`FIELD NAME`, `FIELD TYPE`, `SET AS REQUIRED`, `LABEL`, `HELP TEXT`, `Save`/`Cancel`).
     * *Step 6 (Grading Options):* Icon Selection (Stars, Hearts, Faces, Numbers), Scale stepper, Color Picker, Rubric Builder (Criteria rows, Weight sliders, 100% total validator), Limits configuration (`Session limit`).

3. **Evaluator Review Portal**
   * **Purpose:** Workspace for evaluators to review session submissions.
   * **Components:** Header bar with status and instructions link, Submission sidebar with progress bar and status tabs (`All`, `Reviewed`, `Not Reviewed`), Main Details Panel, Evaluation Input Panel, Sticky Footer (`Save & Next`).

---

### B. Feature / Capability List

1. **Evaluation Plan Management:**
   * Multi-plan support per event workspace.
   * Plan Lifecycle States: `OPEN`, `CLOSED`, `REVIEWED`.
   * Row actions: Edit, Open/Close, Duplicate, Export results, Delete.

2. **Evaluator Assignment & AI Personas:**
   * Assign team members as manual evaluators.
   * Automated AI evaluation capability (`Virtual Evaluators`).
   * Anonymized evaluation option hiding speaker identities.

3. **Session Selection & Filtering:**
   * Dynamic field-based rules engine using `AND`/`OR` conditions.
   * Supported filter dimensions: Track, Tags, Format, Level, Language, Status.

4. **Field-Level Visibility & Custom Questions:**
   * Granular control over visible Session and Speaker details.
   * Custom evaluation questions/fields (Textarea, Dropdown, Radio).
   * Per-field configurability: Required toggle, Label, Help Text.

5. **Grading & Scoring Engines:**
   * Rating scales up to 20 (Stars/Hearts) or 5 (Faces/Numbers) with brand color options.
   * Weighted Rubric Scoring: Multiple criteria with percentage sliders enforcing 100% total weight sum.
   * Evaluation Limits: Configurable cap on total evaluations allowed per submission.

6. **Notifications & Reminders:**
   * Automated weekly reminder emails sent every Monday and 1 day prior to the due date.

### C. Data Model Signals

* **Evaluation Plan:** `id`, `name`/`title`, `instructions`, `status` (`OPEN`, `CLOSED`, `REVIEWED`), `due_date`, `is_anonymized`, `weekly_reminders_enabled`, `include_files_enabled`, `rating_icon_type`, `rating_max_scale`, `rating_color_hex`, `session_limit_count`.
* **Evaluator Assignment:** `plan_id`, `user_id`, `type` (`HUMAN`, `VIRTUAL_AI`).
* **Session Filter Rule:** `plan_id`, `field_name`, `operator` (`IS`, `IS_NOT`, etc.), `value_value`.
* **Evaluation Custom Field:** `id`, `plan_id`, `field_type` (`TEXTAREA`, `DROPDOWN`), `label`, `help_text`, `is_required`.
* **Rubric Criteria:** `id`, `plan_id`, `criteria_name`, `weight_percentage`.
* **Evaluation Submission:** `id`, `plan_id`, `session_id`, `evaluator_id`, `score`, `status` (`PENDING`, `SUBMITTED`).

---

### D. Organizer vs Participant Capabilities

* **Organizer Capabilities (Sessionboard Admin Dashboard):**
  * Create, configure, duplicate, edit, open/close, and delete Evaluation Plans.
  * Define filters, assign evaluators, set display fields, and configure rubrics.
  * Track grading progress and export summary data.

* **Participant / Evaluator Capabilities (External Evaluator Portal):**
  * View assigned submissions filtered by evaluation status.
  * Access permitted session details and attached files.
  * Submit scores, rubric ratings, and feedback comments.

### E. UX/UI Craft Notes

* **Layout & Geometry:**
  * Left sidebar navigation (`240px` fixed width) with collapsible section trees.
  * Form views centered in card layouts (`max-width: 960px`); Evaluator Portal uses a split-screen master-detail layout.
* **Color Palette & Hierarchy:**
  * Accent Primary: Orange (`#FF6B00` / `#F56565`) used for main CTAs and active states.
  * Secondary Actions: Blue (`#2563EB`) and Neutral Light Grey.
  * Badges: `CLOSED` (Orange bg/text), `REVIEWED` (Blue bg/text), `OPEN` (Green bg/text).
* **Form & Input Controls:**
  * Form labels positioned directly above inputs.
  * Clear visual feedback (e.g., dynamic percentage validation text for rubrics, active orange borders on card selections).
  * Right-sliding drawers used for deep configuration tasks like field customization.
