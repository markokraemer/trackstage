### A. Screen Inventory

1. **Fields Management View (`Library -> Fields`)**
   * **Purpose:** Centralized catalog to define, search, sort, and manage internal and custom fields across four core entity domains.
   * **Components:**
     * Category Tabs: `Contact`, `Group`, `Session`, `Evaluation Plan`.
     * Sub-tabs: `All Fields`, `Profile`, `Communication`, `Attribute`, `Custom`.
     * Search Input (`Search fields...`), Sort Dropdown (`A - Z (Name)`), Item Counter (`Showing X-Y of Z fields`).
     * Action Button: `+ Add Field`.
     * Field Row Item: Field Name, Lock Icon (system standard field indicator), Field Key (`slug`), Data Type Badge (`Text`, `Checkbox`, `File`, `Dropdown`, etc.).

2. **Create Field Drawer (`Create [Category] Field`)**
   * **Purpose:** Slide-over modal to configure and initialize a new system attribute.
   * **Components:**
     * `Name *` (Text input)
     * `Language variants` (Button)
     * `Field Type *` (Select dropdown)
     * `Field Description` (Textarea)
     * `Maximum Length` (Character limit feedback label)
     * `Field Level *` (Select dropdown: `Global Field`, `Event Field`)
     * Action Buttons: `Cancel`, `Save Changes`.

---

### B. Feature / Capability List

* **Category Domain Isolation:** Fields are strictly segregated into four categories: Contact, Group, Session, and Evaluation Plan.
* **Scope Levels:** Fields support two scope levels:
  * **Event Field:** Restricted to the current active event instance.
  * **Global Field:** Accessible across all events within the organization tenant.
* **Supported Field Data Types:** `Text`, `Checkbox`, `Countries`, `Currency`, `Date`, `Date & Time`, `Dropdown`, `Email`, `File`, `Number`, `Percent`, `Textarea`.
* **System Lock (Default Fields):** Standard built-in attributes feature a lock icon, preventing full deletion or breaking system dependencies.
* **Multilingual Readiness:** Includes a direct interface hook for `Language variants`.
* **Field Classification Filters:** Secondary filtering by custom sub-categories (`Profile`, `Communication`, `Attribute`, `Custom`).

---

### C. Data Model Signals

* **Field Entity Attributes:**
  * `id` (Text / Unique key)
  * `name` (String, required)
  * `slug` / `system_key` (Auto-generated snake_case string)
  * `category` (Enum: `Contact`, `Group`, `Session`, `Evaluation_Plan`)
  * `sub_category` (Enum: `Profile`, `Communication`, `Attribute`, `Custom`)
  * `field_type` (Enum: `Text`, `Checkbox`, `Countries`, `Currency`, `Date`, `Datetime`, `Dropdown`, `Email`, `File`, `Number`, `Percent`, `Textarea`)
  * `description` (Text, optional internal notes)
  * `max_length` (Integer, default: 255)
  * `scope_level` (Enum: `Event`, `Global`)
  * `is_system_locked` (Boolean)

---

### D. Organizer vs Participant

* **Organizer Side:**
  * Full access to configure, scope (`Global` vs `Event`), search, and generate custom fields within the `Library -> Fields` administration module.
* **Participant Side:**
  * Indirect access: Custom fields defined by organizers automatically render dynamically inside public forms, CFP submissions, speaker portals, and evaluation sheets.

---

### E. UX/UI Craft Notes

* **Layout Structure:** Fixed left sidebar navigation, top application header, content header with breadcrumbs/title, sub-navigation tabs, search/filter control row, and a vertical list container.
* **Drawer Behavior:** Right-side slide-over panel (~400px wide) with dark overlay backdrop.
* **Form Field Alignment:** Field labels are positioned directly above input controls with red asterisk icons (`*`) indicating required inputs.
* **Visual Identifiers:** Locked system fields display a discrete padlock icon inline next to the field label. Technical field slugs are displayed directly beneath the field label in gray monospace/subtext styling.
