### Section A: Screen Inventory

1. **Contacts Listing Screen (`Contacts -> All Contacts`)**
   * **Purpose:** Central repository to view, filter, add, and manage event contacts.
   * **Components:** Left navigation bar, top bar with user profile/portal view, search box, options dropdown, `+ Add` button, table/grid view toggle, show/hide fields, filter/sort controls, list table with pencil edit icons, row selection checkboxes, pagination count.

2. **Speakers Listing Screen (`Contacts -> Speakers`)**
   * **Purpose:** View contacts currently assigned to sessions as speakers.
   * **Components:** Filter tabs (`All Speakers`, `Primary Speakers`, `Assigned Session`, `Session - Pending`, `Session - Declined`), search bar, data table showing speaker details and status.

3. **"Add People To Event" Modal**
   * **Purpose:** Global org search to prevent duplicate contact creation.
   * **Components:** Search field, search result list items with selection checkboxes, duplicate warning banner, `Add new contact` outline button, `Add To Event` primary button, `Cancel` button.

4. **"Add People to Organization" Modal**
   * **Purpose:** Create a brand new contact entity at the organization level.
   * **Components:** Form fields (`Email *`, `First Name *`, `Last Name *`, `Mobile Phone`, `Headshot` dropzone area), `Save` primary button, `Cancel` button.

5. **Record Settings Layout Screen (`Settings -> Record Settings -> Layouts`)**
   * **Purpose:** Configure contact fields displayed during contact creation.
   * **Components:** Category tabs (`Contact Fields`, `Group Fields`), field search box, `Show/Hide Fields` button, field configuration table (`Name`, `Category`, `Type`, `Level`).

6. **Session Detail Screen (`Sessions -> Detail -> Participants`)**
   * **Purpose:** Assign contacts to session participant roles.
   * **Components:** Role dropdown selectors (`Speakers`, `Chairpersons`, `Moderators`, `Session Submitters`), `Save` button.

---

### Section B: Feature / Capability List

1. **Contact Creation Flow & Deduplication:**
   * Global organization lookup before contact creation.
   * Duplicate warning prompt when searching existing records.
   * Direct import of existing org contacts into specific events.

2. **Contact Access Rules:**
   * Newly created contacts reside in `Contacts -> All Contacts`.
   * Contacts only appear in role-specific views (e.g., `Speakers`) after being assigned to a session role.

3. **Dynamic Form Layout Customization:**
   * Administrative control over visible fields during contact creation (`Settings -> Record Settings -> Layouts`).
   * Field configuration options for field visibility, category assignments, and data types (Email, Text, Phone, File upload, Wysiwyg).

4. **Session Assignment:**
   * Multi-role participant support per contact (`Speakers`, `Chairpersons`, `Moderators`, `Session Submitters`).
   * Dynamic lookup and auto-complete assignment from session participant settings.

---

### Section C: Data Model Signals

1. **Contact Entity Attributes:**
   * `Email` (Required, String)
   * `First Name` (Required, String)
   * `Last Name` (Required, String)
   * `Mobile Phone` (Optional, String)
   * `Home Phone` (Optional, String)
   * `Job Title` (Optional, String)
   * `Company Name` (Optional, String)
   * `Headshot` (Optional, File)
   * `Biography` (Optional, Rich Text / Wysiwyg)
   * `Zip` (Optional, String)

2. **Relationships & Roles:**
   * **Organization Level vs Event Level:** Contacts exist globally at the Organization level and are linked to individual Events.
   * **Session Roles:** Contact linked to Sessions via `Speaker`, `Chairperson`, `Moderator`, or `Session Submitter`.
   * **Group Roles:** Contact linked as a group contact for `Sponsor` or `Exhibitor` entities.

3. **Speaker Assignment Statuses:**
   * `Primary Speaker`
   * `Assigned Session`
   * `Session - Pending`
   * `Session - Declined`

---

### Section D: Organizer vs Participant

* **Organizer Capabilities:**
  * Search and manage organization-wide contacts.
  * Create new contacts manually or import existing contacts into events.
  * Customizing contact creation field layouts via event settings.
  * Assigning contacts to session roles (Speakers, Moderators, etc.).

* **Participant Capabilities:**
  * Profile completion and updating via the Portal interface (implied by narration: *"request additional information from the contact through the portal"*).

### Section E: UX/UI Craft Notes

* **Layout Structure:** Standard SaaS split-screen layout with fixed left sidebar navigation (~240px wide) and scrollable main content area.
* **Modal Overlay:** Centered modal dialogues over a dimmed background backdrop. Modals feature dark header title bars, clear section banners, and bottom action toolbars.
* **Button Hierarchy:**
  * Primary actions use prominent filled orange buttons (`+ Add`, `Add To Event`, `Save`).
  * Secondary actions use outlined/ghost style buttons (`Add new contact`) or text buttons (`Cancel`).
* **Table Styling:** Standard grid rows with selection checkboxes on the left, action icons (pencil edit), bold clean text, and generous padding for high legibility.
* **Color Palette:**
  * Brand Primary: Dark navy blue top headers and navigation bars.
  * Accent/Action: Vibrant orange for primary buttons.
  * Banners: Soft blue backgrounds for contextual tips and warning notifications.
