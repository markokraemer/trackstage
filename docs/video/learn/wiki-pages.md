### A. Screen Inventory

1. **Resources List Page** (`Portals -> Resources`)
   * **Purpose**: Displays created wiki pages grouped by section/category with search capability.
   * **Components**: Header `Resources`, Search bar `Search pages...`, `+ Add Page` button, Accordion page groups with update timestamps.
2. **Add Page Drawer** (`Portals -> Resources -> + Add Page`)
   * **Purpose**: Form drawer for creating/editing wiki pages.
   * **Components**: Drawer header `Add Page`, `Title` field, `Subtitle` field, `Page Content` rich text editor toolbar, `Cancel` and `Create Page` buttons.
3. **Portals List View** (`Portals -> Portals`)
   * **Purpose**: Overview of created participant portals and configuration access.
   * **Components**: Header `Portals`, `+ Create Portal` button, search bar, `Contact Portals (5)` and `Group Portals (1)` tabs, portal cards with rule summary, chips (`Filters: 3`, `Assigned to: 1`), and `...` action menu.
4. **Portal Builder / Assign Items Step** (`Portals -> Edit Tasks`)
   * **Purpose**: Multi-step wizard to assign tasks, files, and resources to portals.
   * **Components**: 5-step horizontal stepper, `Resources` accordion widget with `+ Add`, `Manage`, `Learn more` actions, assigned content list.
5. **Add Resources Modal** (`Edit Tasks -> Resources -> + Add`)
   * **Purpose**: Dialog to select and attach wiki pages to the portal.
   * **Components**: Search input, checkbox resource list, `Cancel` and `Add Selected` buttons.
6. **Participant Portal Interface** (End-user view)
   * **Purpose**: Portal dashboard seen by speakers/contacts.
   * **Components**: Header logo, `Session Tasks`, `My Tasks`, blue `Resources` banner containing attached `Wiki Pages`.

---

### B. Feature / Capability List

* **Wiki Page Creation**: Support for titled wiki pages with optional subtitles and rich text formatted content.
* **Rich Text Toolbar**: Bold, italic, underline, strikethrough, script modifiers, text alignment, lists, hyperlinks, images, and formatting reset.
* **Portal Resource Assignment**: Link created wiki pages to specific portals via multi-step portal editor.
* **Participant Portal Display**: Dedicated read-only resource viewing area for speakers/contacts within their assigned portal.
* **Page Search & Organization**: Instant search filtering on wiki pages and grouping by event phase/category.

---

### C. Data Model Signals

* **Resource / Wiki Page**:
  * `Title` (String, required)
  * `Subtitle` (String, optional)
  * `Page Content` (HTML / Rich Text)
  * `Updated Date/Time` (Timestamp)
* **Portal**:
  * `Name` (String)
  * `Target Type` (Contact Portal vs. Group Portal)
  * `Criteria / Rules` (Text description of logic)
  * `Filter Count` (Integer)
  * `Assigned Contact Count` (Integer)
  * `Assigned Resources` (Many-to-Many relation to Resource/Wiki Page)

---

### D. Organizer vs Participant

* **Organizer Actions**:
  * Create, edit, search, and manage Wiki Pages.
  * Create, edit, and configure Portals.
  * Assign Wiki Pages/Resources to specific target Portals.
* **Participant Actions**:
  * Access assigned Portals.
  * View assigned Wiki Pages and resource documentation.

---

### E. UX/UI Craft Notes

* **Layout Geometry**: Left sidebar navigation (~240px wide) with expandable module trees; slide-over drawer on right for entity creation; card-based workflow inside multi-step wizards.
* **Color Hierarchy**: Primary branding in bold blue (`#185adb` / `#000000`), key highlight accents in orange on focused borders/active selections.
* **Component Styling**: Rounded card containers, soft border outlines, status counts displayed inside pill-style badges, crisp typography with distinct bold headers and grey helper text.
