### A. Screen Inventory

1. **Agenda - List View**
   * **Purpose:** Tabular overview of all sessions with custom filtering and tab views.
   * **Components:** Filter tabs (`All Sessions`, `Upcoming`, `Past`), Sidebar controls (`Edit View`, `Hide/Show Fields`, `Add Filter +`, `Add Sort By +`), Data Table (`Status`, `Title`, `CEU Credits`, `Description`, `Starts At`), Action buttons (`Drafts`, `Options`, `+ Add`).

2. **Agenda - Day / Week / Month Views**
   * **Purpose:** Time-grid calendar planning interfaces.
   * **Components:** Date range navigators, time-grid canvas, Right "Sessions" sidebar drawer (`Scheduled`, `Unscheduled` tabs, search field, draggable session cards).

3. **Agenda - Rooms View**
   * **Purpose:** Matrix view showing sessions mapped across individual rooms.
   * **Components:** Room column headers (with capacity indicators), time axis, search input, zoom controls (`100%`).

4. **Edit Session Modal**
   * **Purpose:** In-line editing of detailed session properties.
   * **Components:** Navigation tabs (`Details`, `Other`, `Files`, `Submissions`), Fields (`Session ID`, `Title`, `Status`, `CEU Credits`, `Starts At`, `Ends At`, Rich-text editor), Action button (`Save Session`).

5. **Conflicts Page**
   * **Purpose:** Automated detection and resolution of overlapping sessions or double-booked speakers.
   * **Components:** Unresolved list table (`Session ID`, `Title`, `Conflicts`, `Open` link), Refresh timestamp.

6. **Embeds Page**
   * **Purpose:** Web widget generation for public agenda publishing.
   * **Components:** Embed table (`Name`, `Format`, `Enabled`, `ID`, `Actions`), Button (`+ Add Embed`).

7. **Agenda Settings Page**
   * **Purpose:** Administrative rules defining calendar bounds, status visibility, format durations, and room visibility.
   * **Components:** Time pickers (`Day Start Time`, `Day End Time`), Multi-select pills (`Session Statuses`), Mapped inputs (`Session Format`, `Default Duration`, `+ Add format`), Radio selection (`Room Visibility`), Action button (`Save`).

---

### B. Feature / Capability List

* **Multi-Layout Calendar Visualizations:** Toggle agenda between List, Day, Week, Month, and Rooms matrix views.
* **Drag-and-Drop Scheduling:** Drag unscheduled sessions from the right sidebar drawer onto time slots in Day, Week, or Rooms views.
* **Format-Driven Auto-Duration:** Auto-calculate session end times based on pre-configured format durations (e.g., Lightning Talk = 30 min).
* **Multi-Status Scheduling Filters:** Configure which session status types (e.g., Pending, Accept Queue, Accepted) are allowed on the calendar.
* **Room Visibility Controls:** Limit displayed rooms on the Rooms view to manage large venue scheduling.
* **Conflict Detection System:** Automatically detect and flag double-booked speakers or room collisions with direct link resolution.
* **Publishing Embeds:** Generate styled HTML embed codes for external websites with live cache-refresh action tools.

---

### C. Data Model Signals

* **Session:** ID (`SESS-XX`), Title, Description (rich text), Status (`Accepted`, `Pending`, `Accept Queue`), CEU Credits, Start Time, End Time, Format, Room/Location.
* **Session Format:** Format Name, Default Duration (minutes/hours).
* **Room:** Name, Capacity.
* **Speaker / Contact:** Name, Assigned Session IDs (used for collision check).
* **Embed:** Name, Format (`Styled HTML`), Enabled flag, Embed ID code.

---

### D. Organizer vs Participant

* **Organizer (Back-Office UI):** Access to grid layout building, drag-and-drop scheduling, conflict detection, operational settings, and embed configuration.
* **Participant (Front-Office View):** Consumes the final schedule via public HTML website embeds.

---

### E. UX/UI Craft Notes

* **Sidebar & Layout Geometry:** Dark navy left sidebar navigation (`width ~240px`). Top horizontal view switcher tabs (`List`, `Day`, `Week`, `Month`, `Rooms`, `Conflicts`, `Settings`).
* **Sidebar Drawer:** Persistent right-hand drawer (`width ~300px`) holding "Sessions" (`Scheduled` vs `Unscheduled`) for calendar drag-and-drop.
* **Color Hierarchy:**
  * Primary Actions: Solid orange buttons (`Save`, `Save Session`).
  * Secondary Actions: Blue links (`+ Add format`, `Open`).
  * Status Badges: Green pill badges for `Accepted`, light orange for `Pending`.
* **Form Layout:** Labels positioned directly above inputs; multi-select fields use dismissible inline tags/chips.
