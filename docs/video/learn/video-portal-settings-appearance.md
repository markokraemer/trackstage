### A. Screen Inventory

1. **Portals Index (`Portals -> Portals`)**
   - **Purpose:** Manage speaker/participant portal configurations and portal assignments.
   - **Components:** Nav sidebar, search input (`Search portals by name...`), button (`+ Create Portal`), tabs (`People Portals (0)`, `Group Portals (1)`), portal card (`Default People Portal`), options menu (`Copy Link`, `Edit Criteria`, `Edit Settings`, `Edit Appearance`, `Tasks`, `Duplicate`, `Delete`).

2. **Portal Configuration Wizard: Configuration (`Portals -> Edit Settings`)**
   - **Purpose:** Configure functional behavior, task deadlines, permissions, and automated email rules for a portal.
   - **Components:** Stepper (`1 Select participants`, `2 Assign items`, `3 Configuration`, `4 Appearance`), action buttons (`< Back`, `Continue`), toggles (`Control Session Visibility`, `View Session Submission Form from Portal`, `Always Show Tasks`, `Extend Task Deadlines`, `Manage Profile`, `Manage Related Sessions and Participants`, `Use Session Client ID`, `Send Weekly Digest Email`, `Email Notifications`), dropdown (`Final Deadline`), side preview panel.

3. **Portal Configuration Wizard: Appearance - General (`Portals -> Edit Appearance -> General`)**
   - **Purpose:** Customize branding, welcome text, logos, colors, and custom CSS for the portal interface.
   - **Components:** Tabs (`General`, `Manage Fields`), input (`Title`), WYSIWYG editor (`Welcome Message`), upload buttons (`Logo Image`, `Background Image`), color picker (`Accent Color`), textarea (`Advanced Custom CSS Code`), button (`Save`), side preview panel.

4. **Portal Configuration Wizard: Appearance - Manage Fields (`Portals -> Edit Appearance -> Manage Fields`)**
   - **Purpose:** Configure field-level visibility, read-only locking, and permissions across participant and session objects.
   - **Components:** Sub-tabs (`Contact Fields`, `Session Fields`, `Contact Participants`, `Group Participants`), button (`Show/Hide Fields`), search (`Search by name...`), table columns (`Name`, `Category`, `Type`, `Level`, `Created At`, `Updated At`, `Actions`), row context menu (`Lock`, `Remove`), header button (`Done`).

### B. Feature / Capability List

- **Portal Session Visibility:** Ability to enable/disable session access for portal users.
- **Submission Form Access:** Toggle to grant access to original submission forms from within the portal.
- **Accepted-Only Task Visibility:** Restrict task visibility exclusively to accepted speakers.
- **Extended Deadline Rules:** Configurable task grace periods up to 31 days past original due date.
- **Profile Self-Service Control:** Enable/disable contact profile editing capabilities while retaining profile widget layout.
- **Co-Presenter Editing:** Allow primary speakers to edit details for co-presenters and linked sessions.
- **Client ID Display Override:** Option to substitute internal Session ID with external Client Session ID.
- **Automated Digest & Alerts:** Configurable weekly task digests and instant email notifications upon task assignment.
- **Custom Portal Branding:** Per-portal custom welcome message, custom logo (100x100), background header image (1920x200), accent color, and custom CSS injection.
- **Field-Level Access Controls:** Fine-grained field exposure controls across Contacts, Sessions, Participants, and Groups with individual field locking (read-only) and removal.

### E. UX/UI Craft Notes

- **Layout Structure:** Dual-pane layout on wizard configuration screens with form settings on the left (~60% width) and a real-time responsive interactive portal preview frame on the right (~40% width).
- **Navigation Flow:** Top header wizard bar with clean 4-step horizontal stepper (`1 Select participants` -> `2 Assign items` -> `3 Configuration` -> `4 Appearance`).
- **Button Hierarchy:**
  - Primary save/completion actions use high-contrast solid buttons (`Continue` / `Done` in blue, `Save` in orange `#E03131`).
  - Secondary actions use outline text buttons (`< Back`, `Show/Hide Fields`).
- **Toggles & Inputs:** Standardized iOS-style rounded pill toggles (Green `#28A745` for active, Gray for disabled). Custom hex color inputs with embedded square color preview tile.
- **Table Density & Formatting:** High-density data grid in field management with light gray borders, clean inline status text, and standard ellipses context drop menus (`Lock`, `Remove`).
